# ELC영어공부방 홈페이지

인천 부평구 부개동 ELC영어공부방의 중학교 영어 내신 전문 홈페이지입니다.

## 주요 구성

- ELC 수업 철학과 학교별·학생별 맞춤 관리 소개
- 이정임 원장 소개
- 네 단계 내신 관리 방식
- 학부모 학습 피드백 안내
- 전화 및 이메일 무료 상담 연결
