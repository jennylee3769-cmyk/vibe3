# ELC영어공부방 홈페이지

## 서비스 소개

ELC영어공부방은 인천 부평구 부개동의 중학교 영어 내신 전문 공부방입니다.<br />
학생과 학부모가 수업 대상, 일정, 장소와 모집 상태를 한눈에 확인할 수 있습니다.<br />
관심 있는 수업을 살펴보고 온라인으로 무료 영어 학습 상담을 신청할 수 있습니다.

## 배포 주소

- 홈페이지: [https://vibe3-coral.vercel.app/](https://vibe3-coral.vercel.app/)
- 수업 목록: [https://vibe3-coral.vercel.app/list/](https://vibe3-coral.vercel.app/list/)

## 주요 기능

1. **공부방 안내**: ELC영어공부방의 교육 방향, 수업 특징과 원장 소개를 확인할 수 있습니다.
2. **수업 검색과 필터**: 수업명, 지역과 학년을 기준으로 원하는 수업을 찾을 수 있습니다.
3. **수업 상세 보기**: 수업 대상, 내용, 일정, 장소, 교재와 모집 상태를 확인할 수 있습니다.
4. **회원 수업 관리**: 이메일로 가입·로그인한 뒤 수업을 등록하고 마이페이지에서 수정하거나 삭제할 수 있습니다.
5. **무료 상담 신청**: 홈페이지에서 상담 내용을 작성해 ELC 상담 이메일로 전달할 수 있습니다.

## 사용 기술

- **화면 구성**: HTML, CSS, JavaScript
- **개발 및 빌드**: Vite
- **회원가입·로그인·수업 데이터·이미지 저장**: Supabase
- **상담 이메일 전송**: Resend
- **인터넷 배포**: Vercel

## 실행 방법

### 1. 준비하기

이 프로젝트를 실행하려면 컴퓨터에 [Node.js](https://nodejs.org/)가 설치되어 있어야 합니다.

PowerShell을 열고 프로젝트 폴더로 이동합니다.

```powershell
cd D:\vibe3
```

필요한 프로그램을 설치합니다.

```powershell
npm.cmd ci
```

### 2. 홈페이지 실행하기

```powershell
npm.cmd run dev
```

명령 실행 후 브라우저에서 다음 주소를 엽니다.

- 첫 화면: [http://localhost:3000/](http://localhost:3000/)
- 수업 목록: [http://localhost:3000/list/](http://localhost:3000/list/)

실행을 끝내려면 PowerShell에서 `Ctrl+C`를 누릅니다.

### 3. 배포용 파일 확인하기

```powershell
npm.cmd run build
```

오류 없이 완료되면 배포용 파일이 `dist` 폴더에 만들어집니다.

## 외부 서비스 설정

회원가입, 수업 데이터와 상담 이메일 기능을 사용하려면 Supabase와 Resend 설정이 필요합니다. 필요한 환경변수 이름은 `.env.example`에서 확인할 수 있으며, 실제 비밀번호나 API 키는 GitHub에 올리지 않습니다.

Vite 개발 서버에서는 화면을 확인할 수 있지만 `api` 폴더의 상담 이메일 같은 서버 기능은 실행되지 않습니다. 해당 기능은 Vercel처럼 서버 API를 지원하는 배포 환경에서 확인해야 합니다.
