# ELC영어공부방 홈페이지

인천 부평구 부개동 ELC영어공부방의 중학교 영어 내신 홈페이지입니다. 탑다운 안내 메뉴, 수업 목록, 온라인 무료 상담 문의를 제공합니다.

- Production: https://vibe3-coral.vercel.app
- 수업 목록: `/list/`
- 문의 API: `/api/contact`

기존 강의 교안과 모든 참고 자료도 아래 경로와 Git 이력에 그대로 보존되어 있습니다.

## Codex Vibe Coding 강의 교안

1~5회차를 좌측 회차 네비게이션으로 전환하는 React + Vite 웹 슬라이드입니다. 3회차의 기존 교안과 복사 버튼, 키보드 이동, 목차, 진행바는 유지하고 1·2·4·5회차도 참고 이미지의 페이지 수에 맞춰 연결했습니다.

## 실행

```powershell
npm install
npm run dev
```

브라우저에서 [http://localhost:3000/slides.html](http://localhost:3000/slides.html)을 엽니다. `1`~`5` 회차 버튼, `←` `→` 키, 하단 버튼으로 이동할 수 있습니다. URL 해시는 새로고침 뒤에도 회차와 페이지를 유지합니다.

## 구조

- `src/main.jsx` — 공통 슬라이드 화면, 회차 이동, 복사, 목차, 체크리스트
- `src/slides.js` — 3회차 원본 데이터와 1·2·4·5회차 데이터
- `src/style.css` — 16:9 발표 화면과 반응형 스타일
- `이신우 강의 3기 1강`, `이신우 강의 3기 2강 교안`, `이신우강의 3기 4강`, `이신우 강의 3기 5강` — 참고 이미지 원본
- `qa/` — 기존 및 추가 검수 결과

모든 파일과 참고 이미지는 이 프로젝트 폴더 안에 보존되어 있습니다.
