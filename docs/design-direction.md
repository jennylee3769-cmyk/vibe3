# ELC영어공부방 디자인 방향

- 작성일: 2026-09-07
- 비교 기준: `https://elc-academy-hp.vercel.app/`
- 목표: 중학생과 학부모가 첫 화면에서 ELC의 차별점과 상담 방법을 즉시 이해하는 홈페이지

## 디자인 토큰

- 칠판 잉크 `#173F3A`: 신뢰와 집중을 만드는 주색
- 깊은 잉크 `#0D2B28`: 철학과 푸터의 대비색
- 교재 종이 `#F8F3E9`: 오래 보아도 편안한 바탕색
- 첨삭 코랄 `#E95D45`: 원장의 직접 관리와 행동 유도
- 형광펜 옐로 `#F5C95C`: 핵심 문장의 강조
- 연한 민트 `#DCEBE6`: 차분한 보조 배경

## 타이포그래피

- 큰 제목: `Noto Serif KR` — 교육의 신뢰감과 문장 중심의 인상
- 본문: `Noto Sans KR` — 모바일에서도 읽기 쉬운 설명
- 영문 표기와 숫자: `DM Sans` — 경력과 단계 정보를 선명하게 구분

## 레이아웃

```text
[고정 헤더 / 무료 상담]
[핵심 문장             | 수업 이미지 + 30년]
[검증된 정보 4개]
[수업 철학 / 설명]
[네 단계 관리 방식]
[원장 소개 / 사진]
[학부모 피드백 / 상담 이미지]
[전화·이메일·오프라인 위치]
```

## 시그니처

교재에 직접 남긴 듯한 코랄색 원, 밑줄, 손글씨 메모를 한정적으로 사용한다. 장식이 아니라 ‘학생마다 다른 부분을 원장이 직접 발견하고 표시한다’는 ELC의 관리 방식을 시각화한다.

## 기존 홈페이지에서 개선한 점

- 일반적인 학원 카드 나열 대신 ELC의 수업 철학에서 시작하는 이야기 구조로 변경
- 경력 숫자보다 학생을 어떻게 살피는지 먼저 이해하도록 정보 순서를 재편
- 전화와 이메일 상담을 데스크톱·모바일 모두에서 쉽게 찾도록 고정 동선 제공
- 기존 홈페이지의 확인 가능한 문구와 이미지만 사용하고 새로운 성과나 후기는 만들지 않음
