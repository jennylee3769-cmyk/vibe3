# ELC 영어 MVP 기획서

- 문서 버전: v0.2
- 작성일: 2026-09-07
- 상태: 핵심 운영 정책 확정

## 1. 서비스 개요

### 서비스 한 줄 정의

ELC 영어는 학부모가 자녀에게 맞는 중등 영어 내신 수업을 확인하고 오프라인 무료 상담을 신청·관리할 수 있는 서비스다.

### 주 사용자

- **중학생:** 학년과 학교 진도에 맞는 오프라인 내신 수업을 제공받는 학습자
- **학부모:** 계정을 만들고 자녀 정보, 수업 정보, 무료 상담 신청을 관리하는 핵심 사용자
- **운영자:** 수업과 학습 자료를 등록하고 무료 상담 신청 내역을 관리하는 사용자

### MVP가 해결할 문제

1. 학생과 학부모가 어떤 수업을 제공하는지 한눈에 파악하기 어렵다.
2. 학년, 단원, 수업 일정 등 신청에 필요한 정보가 여러 곳에 흩어져 있다.
3. 관심 수업을 확인한 뒤 무료 상담을 요청하고 연락 상태를 확인하는 과정이 불명확하다.

### MVP의 핵심 이용 흐름

`첫 화면 → 수업 목록 → 수업 상세 → 학부모 로그인 → 무료 상담 신청 → 마이페이지에서 상태 확인`

> 수업은 오프라인으로 운영한다. 학부모가 하나의 계정에서 자녀 정보를 관리하며, MVP의 등록 기능은 결제나 수강 확정이 아닌 무료 상담 신청과 진행 상태 확인까지만 다룬다.

## 2. 화면 목록

| 화면 | 목적 | 핵심 구성 요소 | 주요 행동 |
|---|---|---|---|
| 첫 화면 | 서비스의 대상과 가치를 빠르게 전달 | 서비스명, `중등내신수업` 소개, 핵심 장점 3개, 둘러보기 버튼 | 수업 목록으로 이동 |
| 목록 | 개설된 내신 수업을 비교·탐색 | 학년 필터, 과목/영역 필터, 수업 카드, 모집 상태 | 필터 적용, 상세 열기 |
| 상세 | 한 수업의 상담 판단에 필요한 정보 제공 | 수업명, 대상 학년, 설명, 일정, 장소, 교재, 모집 상태 | 무료 상담 신청 화면으로 이동 |
| 등록 | 선택한 수업의 무료 상담 신청 | 학부모 정보, 자녀 정보, 학교/학년, 연락 방법, 개인정보 동의 | 입력 확인, 무료 상담 신청 제출 |
| 로그인 | 학부모 본인 확인 및 자녀·상담 기록 연결 | 이메일 또는 휴대전화, 비밀번호, 로그인 버튼 | 로그인, 가입 안내 확인 |
| 마이페이지 | 학부모 정보, 자녀 정보와 상담 상태 확인 | 학부모 정보, 자녀 목록, 상담 신청, 진행 상태 | 상담 상세 확인, 정보 수정 |

### 화면별 최소 요구사항

#### 첫 화면

- 서비스 이름 `ELC 영어`와 한 줄 소개 `중등내신수업`을 표시한다.
- 중학생과 학부모 모두 이해할 수 있는 소개 문구 3개를 표시한다.
- `둘러보기` 버튼을 누르면 수업 목록으로 이동한다.
- 모바일과 데스크톱에서 핵심 문구와 버튼이 잘리지 않아야 한다.

#### 목록

- 수업 카드에 수업명, 학년, 수업 일정, 모집 상태를 표시한다.
- 최소한 학년별로 수업을 좁혀 볼 수 있어야 한다.
- 조건에 맞는 수업이 없을 때 다음 행동을 안내하는 빈 화면을 표시한다.

#### 상세

- 상담 신청 전에 알아야 할 수업 대상, 학습 내용, 일정, 장소, 교재, 모집 상태를 표시한다.
- 모집 중인 수업에서만 무료 상담 신청 버튼을 활성화한다.
- 정해지지 않은 정보는 임의로 생성하지 않고 `확정 후 안내`로 표시한다.

#### 등록(무료 상담 신청)

- 필수 항목과 선택 항목을 구분한다.
- 제출 전 개인정보 수집·이용 동의를 받는다.
- 상담 신청 후 접수 여부와 운영자의 연락 예정 절차를 명확히 안내한다.

#### 로그인

- 로그인 실패 시 원인과 해결 방법을 함께 표시한다.
- 로그인하지 않은 사용자가 상담을 신청하면 학부모 로그인 화면으로 이동한다.
- 학생용 별도 로그인 계정은 제공하지 않는다.

#### 마이페이지

- 현재 상담 신청 상태를 `접수`, `연락 예정`, `상담 확정`, `완료`, `취소` 중 하나로 표시한다.
- 학부모는 자신의 정보, 등록한 자녀 정보, 해당 자녀의 상담 기록만 볼 수 있어야 한다.

## 3. 저장해야 할 데이터

### 사용자 및 학생 정보

| 항목 | 필드명 | 형식 | 필수 | 설명 |
|---|---|---|---|---|
| 사용자 식별자 | `user_id` | UUID 문자열 | 예 | 사용자 고유 ID |
| 사용자 유형 | `role` | 열거형: `parent`, `admin` | 예 | 학부모와 운영자 구분 |
| 이름 | `name` | 문자열, 2~30자 | 예 | 사용자 이름 |
| 이메일 | `email` | 이메일 문자열 또는 `null` | 아니요 | 로그인 또는 안내 수신 보조 수단 |
| 휴대전화 | `phone` | 문자열, 숫자와 하이픈 | 예 | 학부모 본인 확인 및 상담 연락용 |
| 비밀번호 | `password_hash` | 해시 문자열 | 예 | 원문이 아닌 안전한 해시만 저장 |
| 학생 식별자 | `student_id` | UUID 문자열 | 학생 정보에 필수 | 학생 고유 ID |
| 학생 이름 | `student_name` | 문자열, 2~30자 | 예 | 수강 대상 학생 이름 |
| 학교명 | `school_name` | 문자열, 최대 100자 | 예 | 재학 중학교 이름 |
| 학년 | `grade` | 정수: 1, 2, 3 | 예 | 중학교 학년 |
| 학부모 연결 | `parent_user_id` | UUID 문자열 | 예 | 자녀 정보를 관리하는 학부모 계정 연결 |
| 생성 일시 | `created_at` | ISO 8601 날짜·시간 | 예 | 최초 생성 시각 |
| 수정 일시 | `updated_at` | ISO 8601 날짜·시간 | 예 | 최근 수정 시각 |

| 항목 | 필드명 | 형식 | 필수 | 설명 |

| 수업 식별자 | `class_id` | UUID 문자열 | 예 | 수업 고유 ID |

| 수업 장소 | `location` | 문자열, 최대 200자 | 예 | 오프라인 수업이 진행되는 장소 |

| 생성 일시 | `created_at` | ISO 8601 날짜·시간 | 예 | 최초 생성 시각 |
| 수정 일시 | `updated_at` | ISO 8601 날짜·시간 | 예 | 최근 수정 시각 |

| 수정 일시 | `updated_at` | ISO 8601 날짜·시간 | 예 | 상태 또는 내용 수정 시각 |

## 4. 이번 과정에서 만들지 않을 기능

- 온라인 카드 결제, 환불, 현금영수증 및 세금계산서 처리
- 온라인·화상 수업 및 수업 영상 제공
- 학생용 별도 계정과 학생 직접 로그인
- 무료 상담 이후의 결제 및 수강 확정 처리
- 실시간 화상 수업 및 녹화 영상 스트리밍
- 숙제 제출, 자동 채점, 성적표 및 학습 분석
- 학생과 강사 간 실시간 채팅 또는 커뮤니티
- 문자, 카카오톡, 이메일 자동 알림 발송
- 학교별 시험지·문제은행 및 AI 문제 자동 생성
- 여러 강사와 지점의 권한을 관리하는 복잡한 관리자 시스템
- 소셜 로그인, 다중 인증 및 외부 학습 플랫폼 연동
- 추천 알고리즘과 개인별 학습 경로 자동 생성
- 앱스토어용 iOS·Android 네이티브 앱

## 5. MVP 완료 기준

- 사용자가 첫 화면에서 서비스 대상과 목적을 이해할 수 있다.
- 목록에서 학년에 맞는 수업을 찾고 상세 정보를 확인할 수 있다.
- 로그인한 학부모가 등록한 자녀를 선택해 무료 상담을 신청할 수 있다.
- 마이페이지에서 자녀 정보와 상담 진행 상태를 확인할 수 있다.
- 운영자가 수업 정보와 무료 상담 상태를 관리할 수 있다.
- 모바일 390px 이상과 일반 데스크톱 화면에서 가로 스크롤 없이 사용할 수 있다.
- 개인정보와 비밀번호를 안전하게 저장하고 권한에 따라 데이터 접근을 제한한다.

## 6. 확정된 운영 정책

- 수업은 지정된 장소에서 진행하는 오프라인 방식으로 운영한다.
- 학부모만 계정을 만들며, 하나의 학부모 계정에서 한 명 이상의 자녀 정보를 관리한다.
- MVP의 `등록` 화면은 수강 확정이나 결제가 아닌 무료 상담 신청을 처리한다.
